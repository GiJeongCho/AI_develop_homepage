POC부터 온프레미스 운영 배포까지. 아래 6개 영역 중 필요한 단계만 맡기셔도 됩니다.

📹

실시간 영상 객체탐지·트래킹

저고도·원거리 소형 표적까지 잡는 실시간 감시 영상 AI.

  • YOLO 탐지 + 경량 칼만 다중객체 추적 (외형 임베딩 없이 경량)
  • 3단계 매칭 재식별, 라벨 흔들림 억제, 속도 스무딩
  • 저조도·안개·저화질 전처리, TensorRT 54ms/frame
  • FastAPI 무중단 파라미터 조절, 엣지 디바이스 최적화
🔐

온프레미스/폐쇄망 보안 RAG-LLM

인터넷 없는 환경에서 도는 사내 지식 검색·질의응답.

  • 보안등급·업무유형별 문서 접근제어, 벡터DB 거버넌스
  • 지식그래프(Neo4j)로 환각 ~30%↓, 청크 품질평가 + HITL
  • OCR·벡터화·메타데이터 적재, 관리자 파라미터 제어
  • Data Flywheel 재학습 루프 + 경량 파인튜닝
🧠

LLM 파인튜닝·도메인 모델

범용 모델을 우리 도메인에 맞게 학습·경량화·서비스화.

  • 지시문 설계 + 추가학습으로 도메인 정확도 향상 (교정 70→97.8% 사례)
  • TTS/STT 파인튜닝, 태깅 모델 등 태스크 특화
  • 기업 서버 포팅·API 서비스화까지
🤖

AI 에이전트·업무 자동화

반복 업무를 대신 처리하는 자가개선 에이전트.

  • Job 관리형 하네스(실패 자동복구), 질문 맞춤 에이전트 자동 생성
  • 에이전트가 에이전트를 평가, MCP 도구 생성/사용
  • 회의록 화자 분리, 오케스트레이션·진행 보고 자동화
  • 성과: 오류율 ~40%↓ · 생산성 ~30%↑
📊

데이터 파이프라인·최적화·시각화

문제 정의부터 지표까지, 산업공학·통계 기반 접근.

  • ETL·전처리·라벨링 자동화 파이프라인
  • Integer Programming 최적화 (에너지 48.8%↓ 사례)
  • 통계 모델링·부하 예측, Tableau 시각화
