쇼츠 만들기, 이래서 귀찮았죠

대본·성우·이미지·편집·자막을 툴마다 왔다 갔다 하다 지칩니다. 그마저도 '어떤 모델이 지금 제일 좋은지'는 매주 바뀝니다.

🧩

툴이 너무 많다

대본 GPT, 성우 다른 앱, 이미지 또 다른 앱, 편집 프로그램… 왔다 갔다 하다 반나절.

🔄

최고 모델이 계속 바뀜

지난달 1등이 이번 달엔 3등. 매번 뭘 써야 좋은지 따라가기 어렵습니다.

💳

구독료가 아깝다

안 쓰는 달에도 나가는 월 구독. 정작 쓰는 모델은 몇 개뿐인데.

✂️

수정이 번거롭다

한 장면만 고치고 싶은데 처음부터 다시. 자막 얹고 세로 맞추는 것도 일입니다.

그래서 이렇게 풀었습니다

여러 툴을 하나로 묶고, '지금 최고 모델'을 언제든 골라 쓰게 만들었습니다.

🔑

내 API 키로 동작

본인 키를 넣어 쓰므로 별도 구독 종속이 없고, 쓴 만큼만 각 서비스에 냅니다. 키는 로컬 파일에만 저장됩니다.

🏆

리더보드로 최고 모델

대본·음성·이미지·영상 각 단계마다 공개 리더보드(LMArena, Artificial Analysis, TTS Arena 등) 바로가기 버튼. 지금 1등을 확인하고 바로 선택.

🧩

한 번에 끝나는 파이프라인

대본(LLM) → 음성(TTS) → 이미지/영상 → 자막 → 합성(ffmpeg)까지 자동. 툴 사이를 오갈 필요가 없습니다.

💬

미리보기 + 채팅 수정

만들어진 쇼츠를 바로 보고, "3번 장면 더 밝게"처럼 말로 수정. 바뀐 장면만 다시 만들어 빠릅니다.

📱

세로 9:16 · 한국어 자막

세로 비율 크롭 + Ken Burns 줌 + 한국어 자막 굽기까지 자동. 업로드용 mp4로 바로 나옵니다.

🧪

키 없이 오프라인 데모

API 키가 없어도 오프라인 데모로 전체 흐름을 먼저 체험. 결제 전에 감을 잡을 수 있습니다.

주제 한 줄이면 쇼츠가 나옵니다

설정에서 키와 모델을 고른 뒤, 주제만 넣으면 나머지는 자동입니다.

STEP 1 · 설정

키 & 모델 선택

프로바이더별 API 키 입력, 각 단계에서 리더보드를 보고 쓸 모델을 고릅니다. 설정은 즉시 저장됩니다.

STEP 2 · 만들기

주제 입력 → 생성

주제·장면 수·언어·영상 모드를 정하고 실행하면, 대본→음성→이미지/영상→자막→합성이 백그라운드로 돕니다.

STEP 3 · 다듬기

미리보기 & 채팅 수정

바로 재생해 보고 채팅으로 수정 요청. 바뀐 장면만 재생성해 빠르게 완성본 mp4를 뽑습니다.

왜 '내 키'가 유리한가

특정 서비스에 묶이지 않고, 늘 최신을 씁니다

월 구독이 아니라 각 API에 쓴 만큼만 지불합니다. 어떤 회사의 모델이든 자유롭게 갈아탈 수 있고, 새 SOTA 모델이 나오면 목록에 더해 바로 사용합니다. 키는 사용자 로컬에만 저장됩니다.

🔓 구독 종속 없음 · 쓴 만큼 🔀 모델 자유 교체 🖥️ 키는 로컬 저장

먼저 솔직하게 알려드립니다

과장 없이. 도입 전에 알고 계셔야 할 점입니다.

✅

준비물 · 동작

· 쓰려는 단계의 API 키가 각각 필요합니다(대본/음성/이미지/영상).
· Windows 데스크톱 앱 — 설치·최초 세팅은 함께 도와드립니다.
· ffmpeg는 번들되어 별도 설치가 필요 없습니다.
· 키 없이 오프라인 데모로 흐름을 먼저 확인할 수 있습니다.

⚠️

유의사항

· API 사용료는 각 서비스에 사용자가 직접 지불합니다(쓴 만큼).
· 영상 생성(Veo/Kling/Runway)은 비용·시간이 커서 기본은 이미지 모드입니다.
· 키는 로컬에 난독화(암호화 아님) 저장 — 공용 PC는 주의하세요.
· 각 모델의 정책·요금·품질은 제공사 사정에 따라 달라질 수 있습니다.

주제만 던지면, 쇼츠는 자동으로

도입·데모·맞춤 세팅이 궁금하시면 편하게 문의 주세요. 가능 여부와 준비물부터 솔직하게 안내드립니다.
