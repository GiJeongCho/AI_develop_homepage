API 막혀 하루 날림

포이즌 호출빈도 초과에 걸리면 하루 종일 아무것도 안 올라갑니다.

발견부터 판매까지 폐루프 자동화

서버를 켜 두면 아래 흐름이 24시간 스스로 돕니다. 사람은 판매 알림을 확인하고, 원하면 매입만 하면 됩니다.

STEP 1 · 수집

후보 발견

무신사 랭킹 500 + 브랜드 페이지 + 세일·기획전을 로테이션 스캔해 후보 상품을 넓게 긁습니다.

STEP 2 · 비교

진짜차익 계산

포이즌 시세 조회 → 카테고리별 수수료 + 부가세 환급까지 반영해 실제로 남는 금액만 도출합니다.

STEP 3 · 등록

자동 위탁 등록

최소 진짜차익을 넘는 것만, 경쟁 최저가보다 살짝 싸게 걸어 처음부터 노출되게 올립니다.

STEP 4 · 유지

가격·재고 관리

품절·저마진은 자동으로 내리고, 언더컷 당하면 최소마진을 지키며 경쟁가로 리프라이싱합니다.

STEP 5 · 판매

즉시 알림

분 단위 판매 감지 → 텔레그램으로 즉시 알림(발송 48시간 마감·무신사 구매링크 포함).

STEP 6 · 기록

매입·장부

(옵션) 무신사 자동 매입, 엑셀 장부·구글시트 자동 기록까지. 자동매수는 기본 꺼짐.

단순 '가격 비교 알림'과 다른 이유

등록·가격·재고·판매까지 폐루프로 닫고, 리셀러가 가장 자주 막히는 지점을 코드로 해결했습니다.

💰

진짜 남는 것만 올림

부가세 환급·회원 등급할인을 반영한 실매입원가 + 카테고리별 포이즌 수수료로 실수령가를 계산. 최소 차익 미만은 애초에 등록하지 않습니다.

🛡️

오매칭 3중 가드

품번 길이 가드 + 가격배수 가드(무신사가 대비 N배 초과 시 다른 상품 판정) + 브랜드 일치 검증(한글↔영문 토큰맵)으로 엉뚱한 매칭을 차단합니다.

🚦

레이트리밋을 이긴다

혼잡 서킷브레이커(프로브+지수 백오프) + 분당 호출 상한 + 실측 도구로 계정별 지속가능 한도를 재서, '하루 종일 안 올라감' 사고를 막습니다.

🔁

올린 뒤에도 알아서

재고 모니터가 품절·판매중지·저마진을 자동으로 내리고, 언더컷 방어와 타임세일 종료 전 선제 내림까지 상시 돌아갑니다.

⚡

판매 즉시 대응

분 단위 판매 폴링 → 텔레그램 즉시 알림(48시간 발송 마감 표기) → (옵션) 무신사 자동 매수까지 연결됩니다.

🎛️

노코드 웹 컨트롤

설정을 파일이 아니라 웹 대시보드에서 조정. 스캔 사이클·활성 위탁·혼잡 상태·로그를 한눈에 봅니다.

신뢰 포인트

'표시가'가 아니라 '진짜 남는 돈'으로 판단합니다

한국 세무 현실(부가세 환급·등급할인)과 포이즌 카테고리 수수료를 모두 반영해 계산하므로, 헛수익 착시 없이 실제 마진이 확보되는 상품만 등록됩니다.

포이즌 실수령가 = 최저호가 − 판매수수료
실매입원가 = 무신사 표시가 ÷ (1 + 부가세율)
진짜차익 = 실수령가 − 실매입원가

한 줄로 요약하면

💸 표시가 말고 진짜 남는 돈으로 판단 🚦 API 막혀 하루 날리는 일 없게 🔁 올리는 것까지가 아니라 팔릴 때까지 관리 🛡️ 엉뚱한 매칭으로 손해 보지 않게 🔒 계정 자격증명은 사용자 로컬에만 저장

안전장치

· 자동매수는 실제 결제가 일어나므로 기본 off — 한도·경고 확인 후 직접 켜야 켜집니다.

· 결제 상한(max_price) 초과 시 중단, 이미 산 것 재매수 방지.
· 계정 자격증명은 사용자 로컬에만 저장(서버 미전송).

유의사항
